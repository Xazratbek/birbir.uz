6) TO'LIQ FRONTEND USER FLOW (MAVJUD API'LAR BO'YICHA)
================================================================================
FLOW A: Signup + onboarding
1. User phone/email kiritadi -> `POST /api/auth/signup/start/`
2. OTP kiritadi -> `POST /api/auth/signup/verify/`
3. Profil ma'lumotlari -> `POST /api/auth/signup/profile/`
4. Avatar yuklaydi -> `POST /api/auth/signup/avatar/`
5. Session holatini tekshirish -> `GET /api/auth/signup/session/{session_id}/`

FLOW B: Login/session
1. Login -> `POST /api/auth/login/` (access + refresh)
2. App ochilganda me -> `GET /accounts/me/`
3. Access eskirsa -> `POST /api/token/refresh/`
4. Logout -> `POST /api/auth/logout/`

FLOW C: Main browsing
1. Categorylar -> `GET /categories/`
2. Listing feed -> `GET /elonlar/` (pagination)
3. Listing detail -> `GET /elonlar/{uuid}/`

FLOW D: Favorite
1. Save/unsave -> `POST /favorites/create/`
2. Favorites list -> `GET /favorites/`
3. Remove -> `DELETE /favorites/delete/`

FLOW E: Seller va profile
1. Sellerlar list -> `GET /accounts/sellers/`
2. Seller detail -> `GET /accounts/sellers/{uuid}/`
3. Follow/unfollow -> `POST /accounts/sellers/{pk}/follow-toggle/`
4. O'z profilini update -> `PATCH /accounts/profile/update/{uuid}/`

FLOW F: Listing create
1. Regions -> `GET /elonlar/regions/`
2. Districts -> `GET /elonlar/regions/{slug}/districts/`
3. Create listing -> `POST /elonlar/create/`
4. Muammo/report -> `POST /elonlar/reports/`

7) ACCESS TOKEN AUTO-REFRESH LOGIKASI (ANIQ TEXNIK TALAB)
================================================================================
Talab:
- Har protected request access token bilan yuboriladi.
- 401 qaytsa requestni darhol fail qilmasdan refresh jarayonini ishga tushiradi.
- Refresh ketayotganda boshqa 401 requestlar queue'da kutadi.
- Refresh muvaffaqiyatli bo'lsa queue dagilar yangi access token bilan retry.
- Refresh xato bo'lsa hammasi reject + logout.

Qo'shimcha:
- Token expiry vaqtini oldindan tekshirib proactive refresh qilish mumkin.
- Tablar oralig'ida session sync (storage event / broadcast channel) bo'lsa yaxshi.
