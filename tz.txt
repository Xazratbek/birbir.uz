1. Region API
- `GET /regions/`
- `GET /regions/{slug}/districts/`

Serializerlar:
- `RegionListSerializer`: `id`, `name`, `slug`, `type`
- `DistrictListSerializer`: `id`, `name`, `slug`, `region`

2. Listing create API
- `POST /listings/`

Request fieldlar:
- `title`
- `description`
- `price`
- `currency`
- `category_id`
- `latitude`
- `longitude`
- `address`
- `landmark`
- `contact_name`
- `contact_phone`
- `allow_chat`
- `allow_call`
- `allow_telegram`
- `has_delivery`
- `delivery_notes`
- `is_negotiable`
- `images[]`

Backend logika:
- auth user olinadi
- lat/lng dan `Point` yasaladi
- reverse geocode qilinadi
- `region` va `district` DBdan topiladi
- `Listing`, `ListingContact`, `ListingDelivery`, `ListingImage` yaratiladi
- kamida 1 aloqa usuli tanlangan bo'lishi shart
- kamida 1 rasm, ko'pi 10 rasm

Serializerlar:
- `ListingCreateSerializer`
  - `title`
  - `description`
  - `price`
  - `currency`
  - `category_id`
  - `latitude`
  - `longitude`
  - `address`
  - `landmark`
  - `contact_name`
  - `contact_phone`
  - `allow_chat`
  - `allow_call`
  - `allow_telegram`
  - `has_delivery`
  - `delivery_notes`
  - `is_negotiable`
  - `images`
